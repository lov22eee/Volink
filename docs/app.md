# Volink 앱(APK) 화면 · 2026-11-05

PC 웹 화면은 그대로 둡니다. 브라우저 창을 휴대폰 너비로 줄여도 웹 디자인이 나옵니다.
아래 화면은 **안드로이드 앱(APK)에 넣을 화면**이며, `vite --mode app`으로만 만들어집니다.
서버 API·DB·로그인·신청·대기열·QR 출석 규칙은 웹과 같습니다.

## 실행

```bash
cd frontend
npm run dev:app      # http://127.0.0.1:5174 (백엔드 8080을 같은 방식으로 프록시)
npm run build:app    # dist-app/ (APK에 넣을 묶음, git에 올리지 않음)
```

- 코드: `frontend/src/app/` (`index.tsx` 진입·라우팅, `ui.tsx` 공용 부품, `app.css`).
- 진입: `src/main.tsx`가 `import.meta.env.MODE === 'app'`이면 앱 화면을, 아니면 웹 화면(`App.tsx`)을 띄웁니다.
- 웹에서 가져다 쓰는 것: 활동 소식(`news.tsx`), 출석 QR(`checkin.tsx`의 `AttendancePanel`·`CheckInPage`), 장소 고르기(`placePicker.tsx`), 지도(`map.tsx`), 알림 토스트.

## 키보드

- 삼성 한글 키보드(앱 WebView)는 입력 신호 없이 글자를 바꿔 화면과 앱 값이 어긋났음(글자 수 0, 버튼 꺼짐, 다시 그리면 지워짐, 2026-11-05 휴대폰 확인). 키를 뗄 때·조합이 끝날 때·칸을 나갈 때 입력 신호를 다시 보내 값을 맞춤(`useKeyboardAware`).

- 입력칸을 누르면 그 칸이 보이는 영역 가운데쯤으로 올라옵니다(`useKeyboardAware`).
- 키보드가 떠 있는 동안 하단 탭을 숨기고, 아래 고정 버튼은 내용 끝으로 내려 입력칸을 가리지 않습니다.
- 안드로이드(Capacitor, 화면 크기 조절 방식)는 페이지 높이가 줄어들므로 별도 위치 계산 없이 맞습니다. 키보드가 화면을 덮는 브라우저는 `--kb`(키보드 높이)만큼 올려 줍니다.
- 아래에서 올라오는 창(시트) 안의 입력칸은 시트가 키보드 위로 올라가고 시트 안에서 스크롤됩니다.
- 로그인 화면은 키보드가 뜨면 로고를 작게 줄여 입력칸·로그인 버튼이 함께 보입니다.

## APK (2026-11-05, 테스트용)

- 구조: Capacitor 8.5.3이 `dist-app/`을 `frontend/android/`에 넣어 APK로 만듦. 앱 이름 Volink, 패키지 `com.volink.app`, 아이콘·시작 화면은 `node scripts/make-app-icons.mjs`로 다시 그림.
- 카카오 지도: 저장소 변수 또는 비밀 `VOLINK_KAKAO_JS_KEY`(JavaScript 키, 공개용)가 있으면 앱에도 카카오 지도. 카카오 콘솔의 JavaScript SDK 도메인에 `https://localhost`를 등록해야 함. 없으면 그림 지도.
- 서버 주소: 빌드할 때 `VITE_API_BASE`(Actions는 저장소 변수 `VOLINK_SITE`, 없으면 현재 AWS 주소). 앱이 아닌 브라우저(`npm run dev:app`)는 예전처럼 같은 주소·쿠키 방식.
- 로그인 유지: 앱은 `https://localhost`에서 열리므로 쿠키 대신 서버가 응답 본문으로 준 리프레시 토큰을 앱 저장소에 보관하고 `/api/auth/refresh`에 본문으로 보냄(한 번 쓰면 바뀜, 로그아웃 때 지움). 서버는 `APP_ORIGINS`(기본 `https://localhost`)에서 온 요청에만 이렇게 함.
- 카카오·구글: 휴대폰 브라우저(Custom Tab)로 `…/start?app=1` → 끝나면 서버 페이지가 `intent://oauth?code=…#Intent;scheme=volink;package=com.volink.app;end`로 앱을 엶 → 앱이 `#/oauth`로 이어서 로그인. 브라우저가 자동으로 안 넘기면 ‘앱으로 돌아가기’ 버튼.
- 권한: 카메라(출석 QR 찍기), 위치(체크인 200m·내 주변). 처음 쓸 때 휴대폰이 물어봄.
- 상단·하단 안전 영역: Capacitor가 넣는 `--safe-area-inset-*` 값을 먼저 쓰고 없으면 `env(safe-area-inset-*)`.
- 빌드: `.github/workflows/apk.yml` → 실행 결과 Artifacts의 `volink-apk`. 로컬은 Android Studio에서 `frontend/android`를 열어도 됨(`npm run build:app` 뒤 `npx cap sync android`).

### 폰에 설치하기

1. GitHub 저장소 → Actions → ‘Android APK (test build)’ → 가장 위 초록 실행 → 아래 Artifacts의 `volink-apk` 받기(zip 안에 apk).
2. apk를 휴대폰으로 옮겨(카톡 나에게 보내기·구글 드라이브 등) 누르기 → ‘출처를 알 수 없는 앱 설치’ 허용.
3. Play 프로텍트 경고가 나오면 ‘무시하고 설치’(정식 서명 전 테스트용이라 나오는 경고).
4. 새 APK가 ‘앱이 설치되지 않음’으로 막히면 기존 Volink 앱을 지우고 설치(서명 키가 바뀐 경우). 2026-11-05부터 Actions가 디버그 키를 캐시에 보관해 같은 브랜치의 다음 APK는 덮어 설치됨(캐시가 지워지면 다시 한 번 삭제 필요).
