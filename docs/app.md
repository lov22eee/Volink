# Volink 앱(APK) 화면 · 2026-11-05

PC 웹 화면은 그대로 둡니다. 브라우저 창을 휴대폰 너비로 줄여도 웹 디자인이 나옵니다.
아래 화면은 **안드로이드 앱(APK)에 넣을 화면**이며, `vite --mode app`으로만 만들어집니다.
서버 API·DB·로그인·신청·대기열·QR 출석 규칙은 웹과 같습니다.

## 실행

```bash
cd frontend
npm run dev:app      # http://127.0.0.1:5174 (백엔드 8080을 같은 방식으로 프록시)
npm run build:app    # dist-app/ (APK에 넣을 묶음, git에 올리지 않음)
```

- 코드: `frontend/src/app/` (`index.tsx` 진입·라우팅, `ui.tsx` 공용 부품, `app.css`).
- 진입: `src/main.tsx`가 `import.meta.env.MODE === 'app'`이면 앱 화면을, 아니면 웹 화면(`App.tsx`)을 띄웁니다.
- 웹에서 가져다 쓰는 것: 활동 소식(`news.tsx`), 출석 QR(`checkin.tsx`의 `AttendancePanel`·`CheckInPage`), 장소 고르기(`placePicker.tsx`), 지도(`map.tsx`), 알림 토스트.

## 구조

| 찾기 | 검색창, 칩(내 주변·이번 주말·처음 환영·1365 + 분야), 목록/지도 전환. 1365는 위치가 있을 때 20km 안, 신청은 1365에서 |

| 내 활동 | 참여 예정 / 내가 모집 / 완료 기록 |
| 마이 | 프로필·통계(완료 활동·함께한 시간·모집 완료) · 내 활동 기록 · 저장한 봉사 · 관심 분야 · 알림 · 기록·보험 안내 · 로그아웃. 감사 카드는 7주차 기능이라 넣지 않음 |

| 모집 관리(모집자) | 확정·승인 대기·대기·새 질문 숫자, 탭(신청자 / 소식 / 출석). 메뉴: 고치기, 일정 바꾸기(1회·24시간 전까지), 다시 모집, 삭제(신청자 0명) 또는 활동 취소(사유) |

화면마다 가장 중요한 버튼 하나를 아래에 고정합니다. 하단 탭이 있으면 탭 위에, 없으면 화면 맨 아래에 놓아 서로 겹치지 않습니다.

## 키보드

- 입력칸을 누르면 그 칸이 보이는 영역 가운데쯤으로 올라옵니다(`useKeyboardAware`).
- 키보드가 떠 있는 동안 하단 탭을 숨기고, 아래 고정 버튼은 내용 끝으로 내려 입력칸을 가리지 않습니다.
- 안드로이드(Capacitor, 화면 크기 조절 방식)는 페이지 높이가 줄어들므로 별도 위치 계산 없이 맞습니다. 키보드가 화면을 덮는 브라우저는 `--kb`(키보드 높이)만큼 올려 줍니다.
- 아래에서 올라오는 창(시트) 안의 입력칸은 시트가 키보드 위로 올라가고 시트 안에서 스크롤됩니다.
- 로그인 화면은 키보드가 뜨면 로고를 작게 줄여 입력칸·로그인 버튼이 함께 보입니다.

`docs/api.md` 6주차 줄 참고: 활동 취소(사유), 일정 변경 1회, 늦어요(10/20/30분), 못 가요(이유 선택), 활동 강도·실내외·처음 환영, 하루 전 알림, 저장한 봉사(`/api/me/saved`).

## 확인 방법·결과

- `npx playwright test --project app` — 앱 화면 3개 시나리오(로그인 필수·가입 3단계, 만들기→신청→승인→일정 변경 알림, 활동 취소 사유).
- 360·390·430px에서 모든 화면을 찍어 가로 넘침이 없는지 확인(스크립트는 개발 환경 임시 폴더, 저장소에 넣지 않음).
- 실제 휴대폰·실제 키보드·카메라 QR 인식은 APK를 만든 뒤 기기에서 확인해야 합니다. 개발 환경 브라우저에는 바코드 인식 기능이 없어 “휴대폰 기본 카메라로 찍어 주세요” 안내가 나옵니다.

## APK 전에 남은 일

- 앱 안 로그인 유지: 지금은 웹과 같은 리프레시 쿠키 방식. 앱(다른 주소에서 서버 호출)에서는 토큰 보관·CORS가 필요합니다.
- Capacitor 프로젝트·서명 키(사용자가 보관, git 제외)·버전 번호.
- 이 개발 환경은 안드로이드 SDK 주소(`dl.google.com`)가 막혀 있어, APK 빌드는 GitHub Actions나 Android Studio에서 합니다.
