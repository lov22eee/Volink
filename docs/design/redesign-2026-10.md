# 화면 리디자인 · 2026-10-28

5주차 브랜치(`claude/week-05`) 위에서 **지금 있는 화면만** 다시 그렸습니다. API·인증·라우팅·DB·신청/대기열 로직은 바꾸지 않았고, 새 기능(QR·후기·봉사시간·배지·추천·운영 대시보드)이나 가짜 데이터는 넣지 않았습니다.

## 방향

| 화면 | 방향 | 핵심 |
| --- | --- | --- |
| 홈 | 에디토리얼 | 큰 제목·그림, 실제 모집 수 2칸, 모집 중 카드 3개, 참여 방법 4단계 |
| 활동 찾기 | 지도 탐색 | 지도+목록 나란히(데스크톱), 휴대폰은 ‘목록/지도’ 전환 |
| 상세·신청·내 활동·알림·관리 | 미니멀 제품 화면 | 상태 칩 한 종류, 주요 버튼 하나, 남은 자리 막대 |

## 디자인 시스템 (`frontend/src/styles.css` 맨 위 `:root`)

- 색: `--green #245E48`(주요 버튼·선택), `--sage #E9F0E7`(옅은 면), `--bg #F8F9F5`(바탕), `--ink #263B32`(글자), `--amber #E8AD67`(자리 제안·마감 강조). 빨강(`--red`)은 오류에만 씁니다.
- 반지름 `--r-sm/md/lg/pill`, 그림자 `--shadow-1/2`, 머리글 높이 `--header-h`, 좌우 여백 `--page-x`.
- 글꼴: 설치되어 있으면 Pretendard/SUIT, 없으면 시스템 한글 글꼴. **웹 글꼴을 내려받지 않습니다**(오프라인 화면 파일이 외부 요청 없이 열려야 하므로).
- 공통 부품: `status-chip`(ok/wait/off/act/muted), `loading-state`, `account-empty`(빈 화면), `seat-bar`·`seat-meter`(확정·제안 막대), `status-help`(.urgent), `todo-panel`, `list-group`, `form-section`.
- `finder.css`(활동 찾기·장소 창·만들기)의 색 값은 모두 같은 토큰으로 바꿨습니다.

## 화면별 변경

- **공통 틀:** 위쪽 머리글 하나(로고·메뉴·종·이름·로그아웃). 720px 이하에서는 같은 메뉴가 **아래 탭바**로 바뀝니다(CSS만, 메뉴 이름 그대로).
- **홈:** 실제 수치·실제 모집글만 사용. 참여 단계의 ‘QR로 확인’은 아직 없는 기능이라 ‘정한 시간·장소에서 함께해요’로 고쳤습니다.
- **활동 찾기:** 제목·검색줄·지도/목록 정리, 휴대폰 보기 전환, 조건이 있을 때 빈 결과에 ‘조건 모두 지우기’.
- **상세:** 제목 → 신청 상자 → 소개 순(휴대폰). 신청 상자에 확정/제안 막대, 남은 자리, 내 상태 칩, 상태별 한 줄 안내, 자리 제안 마감 시각 강조, 처리 중 표시.
- **신청자 관리(모집자):** 확정·승인 대기·대기 요약 칩, 줄마다 상태 칩과 작은 버튼.
- **내 활동:** 자리 제안이 있으면 맨 위 ‘지금 확인할 일’, 4칸 요약, 탭 안을 다가오는 활동/승인·대기 중/지난 신청으로 묶음.
- **알림:** 새 알림/지난 알림 묶음, 종류별 아이콘, 빈자리 제안 강조, 읽을 것이 없으면 ‘모두 읽음’ 비활성, 불러오기 실패 시 다시 시도.
- **만들기·수정:** 6단계 묶음(활동 정보·장소·일정·인원·소개·확인). 입력 규칙·오류 문구는 그대로.
- **로그인·회원가입:** 왼쪽 소개 3줄, 처리 중 문구.
- **관리:** 위쪽 바로가기(기관 확인 대기·검토 대기 활동·장소 좌표, 개수 표시), 줄마다 처리 중 표시.
