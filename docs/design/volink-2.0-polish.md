# Volink 2.0 다듬기 보고서 · 2026-10-29

PR #18(`claude/nice-gates-bzuw67`)의 Volink 2.0을 바탕으로, 디자인 방향은 그대로 두고 사용성과 완성도를 높였습니다. 작업 브랜치는 `claude/volink-2-polish`입니다. 백엔드·DB·API·인증·신청/대기열 로직은 바꾸지 않았습니다.

전후 그림은 `docs/screenshots/polish/`에 있습니다. 이름이 `<화면>-d.jpg`이면 PC(1440), `-m.jpg`이면 휴대폰(390)이고, 왼쪽이 Before, 오른쪽이 After입니다.

## 검수 방법

- 29가지 상태(비회원·회원·모집자·관리자, 신청 전·승인 대기·대기·자리 제안·확정·취소, 오류 화면 등)를 5개 크기로 캡처했습니다: 1440 · 1024 · 768 · 390 · 360. 수정 전 145장, 수정 후 150장(취소 확인창 추가).
- 캡처할 때마다 가로 넘침과 브라우저 콘솔 오류를 기록했습니다.
  - 수정 전: 넘침 0, 콘솔 오류 1종(로그인하지 않은 방문자의 세션 확인 요청이 401)
  - 수정 후: 넘침 0, 콘솔 오류 0
- 1366·430 크기는 직접 캡처하지 않았습니다. 1440과 1024, 390과 360 사이에 걸리는 레이아웃 구간(1100·860·720px)은 위 캡처로 확인했습니다.

## 화면별 개선

### 공통
- **기존 문제:** 신청·취소·승인 결과가 작은 회색 글 한 줄이라 성공과 실패가 구분되지 않았습니다. 취소 확인은 브라우저 기본 확인창이었습니다. 회색 보조 글이 연초록 배경 위에서 대비 4.2:1로 기준(4.5:1)에 못 미쳤습니다. 처음 오는 사람도 세션 확인 요청이 401로 실패해 콘솔에 오류가 남았습니다.
- **수정:**
  - `Notice`: 성공은 초록 ✓, 실패는 빨강 !, 안내는 회색 i로 표시합니다. 화면 읽기 프로그램이 읽도록 `role=status`를 붙였습니다.
  - `ConfirmDialog`: `alertdialog`, 처음 초점은 안전한 버튼, Esc와 바깥 누르기로 닫힘, 닫히면 원래 버튼으로 초점이 돌아갑니다.
  - 알림 시각을 '오늘 22:48 / 어제 / 10월 26일'로 보여 줍니다.
  - 글자색 `--ink-3`를 #5f6863으로 바꿔 모든 배경에서 4.9:1 이상이 되게 했습니다. 주황 강조색 `--wait`은 #94590f(흰 바탕 5.7:1)입니다.
  - 누르는 요소는 44px 이상으로 맞췄습니다.
  - 버튼에 누를 때 살짝 내려가는 반응을 넣었습니다. '움직임 줄이기' 설정에서는 꺼집니다.
  - 로그인한 적이 있는 브라우저에서만 세션 확인 요청을 보냅니다(로그인 여부 표시만 `localStorage`에 저장, 토큰은 저장하지 않음).
- **기대 효과:** 내가 한 행동이 됐는지 바로 알 수 있고, 실수로 취소할 일이 줄어듭니다.

### 홈
- **기존 문제:** 히어로 그림(분야 그림 3장 모음)이 장식에 그치고, 폰에서는 첫 화면 아래를 크게 차지했습니다. 카드 그림이 장난감처럼 보였습니다. 불러오기에 실패하면 다시 시도할 방법이 없었습니다.
- **수정:**
  - 히어로 오른쪽에 차분한 분야 배지 판을 두고, 그 위에 **실제로 곧 열리는 활동 카드**(제목·일시·장소·인원 막대, 누르면 상세)를 올렸습니다.
  - 폰에서는 장식 판을 빼고 그 카드만 버튼 아래에 둡니다.
  - 분야 커버를 '연한 색면 + 흰 배지 위 분야 아이콘'으로 다시 그렸습니다. 활동마다 도형 위치와 색조가 달라 옆 카드와 겹치지 않습니다.
  - 불러오기 실패 시 '다시 불러오기' 버튼, 빈 목록에는 아이콘과 '활동 만들기'를 넣었습니다.
- **수정 이유:** 첫 화면에서 '지금 참여할 수 있는 것'을 바로 보여 주는 것이 장식보다 서비스 목적을 빨리 전달합니다. 실제 데이터만 쓰고 사진처럼 보이게 하지 않았습니다.
- **남은 것:** 사용권이 있는 실제 사진은 아직 없습니다(개발 환경에서 사진 사이트 접속이 막힘).

### 활동 찾기
- **기존 문제:**
  - 위치를 켜면 '내 주변' 카드가 예전 모양(태그 칩, 초록 버튼)이었고, 폰에서는 그림이 위로 올라가 어수선했습니다.
  - 켜진 필터가 숫자로만 보였습니다.
  - 서버 오류가 '결과 없음'으로 보였습니다.
  - 위치가 정해지면 '활동 목록' 제목이 '내 주변' 위에 겹쳐 보였습니다.
- **수정:**
  - 내 주변 카드를 아래 목록 카드와 같은 모양으로 맞췄습니다: 왼쪽 그림, '동네 활동 · 분야 · 오전' 한 줄, 거리 알약, '자세히 보기 →' 글자 버튼.
  - 검색줄 아래에 **켜진 조건 칩**(누르면 그 조건만 끔)과 '모두 지우기'를 넣었습니다.
  - 목록 요청이 실패하면 빨간 안내와 '다시 불러오기'를 보여 줍니다. 앱 전체의 '다시 시도'와도 함께 다시 불러옵니다.
  - 위치가 정해지면 겹치던 제목을 숨깁니다.
- **유지:** Kakao 지도, 반경 자동 넓히기, 1365 연동, 쪽 나눔, 폰 목록/지도 전환
- **기대 효과:** 무엇으로 걸렀는지, 결과가 없는 건지 오류인지 바로 구분됩니다.

### 활동 상세·신청
- **기존 문제:** 위쪽 그림이 너무 높았습니다(최대 340px). 신청 버튼이 다른 버튼과 크기가 같았습니다. 취소 결과가 작은 글이었습니다.
- **수정:**
  - 커버 높이를 280px로 줄였습니다(폰은 16:8).
  - 신청 버튼을 54px로 키웠습니다.
  - 취소는 확인창을 거칩니다. 확정자가 취소하면 "확정된 자리는 대기 1번에게 넘어가요"라고 미리 알려 줍니다.
  - 결과는 초록/빨강 안내로 보여 줍니다.
- **상태 흐름:** 서버가 주는 상태만 씁니다. 바뀐 것 없음.
  - 신청 가능 → 승인 대기 → 참가 확정
  - 정원 마감 → 대기 신청 → 빈자리 제안 → 수락/거절

### 내 활동
- **수정:** 다가오는 활동과 승인·대기 중은 날짜가 빠른 순, 지난 신청은 최근 순으로 정렬합니다. 자리 제안은 계속 맨 위 '지금 확인할 일'에 있습니다.

### 알림
- **수정:** 시각 표시를 사람이 읽기 쉽게 바꿨습니다. 원래 시각은 마우스를 올리면 보입니다. 터치 영역과 안 읽음/읽음 구분은 2.0 그대로입니다.

### 활동 만들기
- **수정:** 입력 오류 테두리, 확인 체크 줄, 글자 수 칸의 `!important`를 없앴습니다. 대신 범위를 좁힌 선택자를 쓰고, 화면에서 그대로 보이는지 확인했습니다. 서버 검증·위험도 검사는 그대로입니다.

### 로그인·회원가입
- **수정:** 결과 안내를 공통 `Notice`로 통일했습니다. 미리보기에서는 안내(i), 실패는 빨강으로 보입니다. 자동완성 속성(`email`·`username`·`new-password`·`current-password`·`bday`·`tel`)은 그대로 있습니다.

### 관리자
- **수정:** 승인·반려·좌표 저장 결과를 초록/빨강 안내로 구분했습니다. 태블릿(768)에서는 숫자 카드 2열, 그래프 2열로 보이는 것을 확인했습니다.
- **유지:** 관리자 전용 메뉴, 실제 API 통계만 사용

- CSS
  - 토큰을 `styles.css`의 `:root` 하나로 합침. 이전에는 `v2.css`에도 `:root`가 있었음
  - 소스에서 쓰지 않는 클래스 규칙 120개를 postcss로 찾아 지움(상태값을 붙여 만드는 클래스는 예외)
  - 줄 수: `styles.css` 504→420, `finder.css` 280→264, `v2.css` 572→642(새 부품 포함)
  - `!important` 5→1. 남은 1개는 '움직임 줄이기' 설정용 전역 규칙입니다.
- 테스트 변경
  - 취소 시나리오에 확인창 단계를 추가
  - Esc로 닫으면 취소되지 않는지, 초점이 '돌아가기'에 있는지 확인을 추가
  - 검증을 줄인 곳은 없습니다.
