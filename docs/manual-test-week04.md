# 4주차 직접 확인 목록 · 테스트 담당

배포 서버(https://3-104-31-169.sslip.io)에 4주차를 반영한 뒤 확인합니다. 맞으면 O, 다르면 X + 캡처. 관리자 계정은 팀 단톡방으로 따로 받습니다.

| # | 할 것 | 기대 결과 |
|---|---|---|
| 1 | 관리자로 로그인 → 관리 → 장소 좌표에 `37.8x, 127` 입력 후 저장 | "위도, 경도 순서로" 오류 |
| 2 | 카카오맵에서 복사한 실제 좌표를 넣고 만남 지점 적고 저장 | "좌표를 저장했습니다", '좌표 입력됨' |
| 3 | 일반회원으로 그 장소에 활동 만들기 | 공개됨 |
| 4 | 활동 찾기 → [내 주변 찾기] → 위치 허용 | '내 위치 기준 3km', 카드에 거리(km) |
| 5 | 반경을 1km / 10km로 바꾸기 | 거리에 따라 카드가 줄거나 늘어남 |
| 6 | 위치를 '차단'하고 [내 주변 찾기] | '활동 장소 중심을 기준으로 찾습니다' |
| 7 | 소개글에 '어르신' 넣은 활동 만들기 → 내 주변 찾기 | 목록에 없음(관리자 승인 전) |
| 8 | 지도 보기 버튼 | 핀(또는 위치 그림)과 장소 버튼, 누르면 목록이 바뀜 |
| 9 | 날짜·분야·활동 유형 바꾸기 | 조건에 맞는 활동만 |
| 10 | 휴대폰으로 같은 순서 | 화면이 옆으로 넘치지 않음 |

보낼 것: 10개 중 O 개수, X 번호와 캡처.
