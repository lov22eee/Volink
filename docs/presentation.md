# 실제 서비스 화면으로 발표하기

제출한 1주차 보고서는 서비스 흐름·회원 유형·주요 UI·데이터·테스트 **설계**를 정리한 문서입니다. 공개 서비스 화면을 직접 눌러 그 구조를 보여주세요. 발표 메뉴나 슬라이드는 서비스 안에 넣지 않습니다.

## 보여줄 순서

| 순서 | 화면 | 설명할 내용 |
|---|---|---|
| 1 | 활동 찾기 | 주변 활동 목록, 분야·검색어·날짜·유형 필터, 지도·목록 배치 |
| 2 | 활동 카드의 상세 보기 | 일시·장소·정원·시간, 신청→승인/대기→출석→완료 흐름 |
| 3 | 활동 만들기 | 자율·기관 주관 활동 구분, 2~10명·3시간 이내 입력 기준 |
| 4 | 내 활동 | 신청·개설·활동 기록을 구분하는 화면 구조 |
| 5 | 로그인·회원가입 | 일반회원과 기관회원의 입력 차이, 기관 확인 후 주관 활동 개설 |
| 6 | 필요할 때 문서 | README와 architecture.md의 데이터·권한·테스트 설계 |

지도·로그인·가입·신청·기관 승인·저장·완료 기록은 아직 연결되지 않았습니다. 예시 활동이나 입력 화면을 실제 업무 기능의 완성으로 설명하지 않습니다. 발표 자료와 인수인계는 docs에 두고 서비스에는 이용 메뉴만 둡니다.

## 보고서 기준

- 제출 내용과 화면 대응: [service-ui-week01.md](service-ui-week01.md).
- 1주차 복사용 내용: [reports/week-01.md](reports/week-01.md). 전주까지 현황은 비어 있습니다.
- 2026-10-08 실제 수정·검증은 제출 기간 9/28~10/5의 실적으로 소급하지 않습니다.
- 기존 슬라이드는 docs/archive와 docs/slides에 보관된 과거 자료입니다.

## 이후 주차

그 주에 구현한 실제 기능을 같은 서비스 화면에서 보여주고, README의 완료 체크·인수인계·보고서·검증 결과를 함께 main에 전달합니다. 업무 기능이 연결된 시점에 해당 준비 중 안내를 제거하며, API·권한 규칙도 검증합니다.
