# N주차 보고서 · 작성 템플릿

| 항목 | 작성 |
|---|---|
| 조명 | Volink |
| 팀원 | 오준원, 박용빈, 김병수 |
| 프로젝트명 | Volink(볼링크) |
| 작업기간 | 실제 시작일 ~ 실제 종료일 |

## 전주까지 개발 현황 (개발 진도: 실제 평가 후 기입)

```text
1. 이전 주까지 동작하는 화면·기능·환경의 누적 현황:
2. 이전 주 검증 결과 및 아직 해결되지 않은 문제:
3. 이번 주 작업이 이어받은 데이터·명세·코드:
```

※ 1주차는 이 항목을 비워 둡니다. 주차 수만으로 기능 완성률을 계산하지 않습니다.

## 금주 작업 사항

```text
1. 이번 주 실제 구현·수정한 화면 및 사용자 동작:
2. 이번 주 실제 구현·수정한 API·DB·권한·규칙:
3. 실행한 검증·발견/수정한 오류·발표 자료·미완료 사항:
```

## 다음주 작업 예정 사항

```text
1. 다음 주 화면·사용자 흐름·API 연결 작업:
2. 다음 주 서버·데이터·규칙 구현 또는 확정 작업:
3. 다음 주 검증·시연·보고서·인수인계 및 필요한 의사결정:
```

실제 결과를 작성하고, 계획·시안·구현·검증을 구분합니다. 테스트가 실패하거나 실행되지 않았다면 성공으로 적지 않습니다.
