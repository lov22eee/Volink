## 금주 작업 사항

```text
1. 프론트엔드·백엔드·데이터베이스 개발환경을 구성하였다.
   React·Vite·TypeScript 프론트엔드와 Java 21·Spring Boot 백엔드를 생성하고, Docker 기반 MySQL 8.4 및 Flyway 마이그레이션을 구성하였다. 프론트엔드에서 백엔드 API를 거쳐 실제 DB의 시연 데이터를 조회하도록 연결하였다. 로컬 DB 비밀번호는 Git에서 제외된 환경 파일로 관리하고, 소스·문서·실행 절차를 팀 저장소에 정리하였다.

2. 사용자 흐름·화면·핵심 데이터 구조를 설계하였다.
   참가자·모집자·관리자별 화면 흐름과 역할·소유관계 기반 권한 초안을 작성하였다. 사용자, 활동, 장소, 참가, 체크인, 완료 기록, 상태 변경 로그의 핵심 테이블과 ERD 초안을 구성하였다. 홈·활동 목록·상세 미리보기·활동 개설 입력 시안·사용자 흐름·개발 현황 및 1주차 발표 화면을 구현하였다. 활동 개설 시안의 필수 항목, 2~10명 정원, 180분 이내 시간, 안전 안내 확인을 화면에서 검증하도록 구성하였다. 실제 활동 저장·인증·신청 기능은 아직 구현하지 않았다.

3. 시연 데이터와 검증·인수인계 자료를 준비하였다.
   경동대학교 양주 메트로폴캠퍼스 생활권을 기준으로 옥정중앙공원, 독바위공원, 회암사지 역사공원을 장소 후보로 선정하였다. 모집자 2명·참가자 6명·관리자 1명의 시연 페르소나와 활동 시안 3건을 정의하였다. 장소 좌표·이용 조건은 다음 주 확인 대상으로 남겼다. 프론트 빌드, 실제 MySQL 통합 테스트, 브라우저 시나리오 검증을 수행하고 별도 검증 문서에 결과를 기록하였다. 매주 한 명이 주차 전체를 구현한 뒤 README의 완료 표시·미완료·검증 결과·다음 작업을 갱신해 main으로 전달하는 절차와 보고서·발표 자료를 작성하였다.
```

## 다음주 작업 예정 사항

```text
1. 화면·API 연결 명세와 데이터 구조를 확정한다.
   지도·목록 레이아웃을 정리하고 입력값·오류 표시 규칙 및 화면별 API 요구사항을 작성한다. 핵심 ERD와 API 명세, 참가 상태 전이, 역할·소유관계 권한표를 확정하고 신고·증빙·제재·알림 등 후속 데이터 구조를 정리한다.

2. 시연 장소·계정 정의와 안전 규칙을 구체화한다.
   학교 캠퍼스와 시연 장소 후보의 정확한 주소·좌표·공공장소 이용 조건을 확인한다. 시연 계정의 역할과 상태, 활동·참가·출석·기록 데이터 항목을 확정하고 금지 규칙·위험 키워드 및 LOW·REVIEW·BLOCKED 처리 기준을 작성한다.

3. 후속 구현·배포·검증 기준을 정리한다.
   인증·권한 및 활동 개설 구현에 필요한 테스트 시나리오를 준비하고, 비밀값 관리·개인정보·Kakao·S3·EC2 사용 및 배포 비용 기준을 정리한다. 6주차 기본 흐름 연결 목표에 완료 기능을 포함할지 팀에서 결정한다. 2주차 결과를 보여주는 발표 화면과 진행 보고서를 갱신하고 검증 결과·미완료·다음 작업을 다음 담당자에게 main으로 전달한다.
```
