# 3주차 진행 보고서 · 복사용

| 항목 | 작성 |
|---|---|
| 조명 | Volink |
| 팀원 | 오준원, 박용빈, 김병수 |
| 프로젝트명 | Volink |
| 작업기간 | 2026.10.13 ~ 2026.10.19 |
| 역할 | 개발 박용빈 / 테스트 김병수 / 확인·발표 오준원 |

개발 진도는 팀이 정해 기입합니다. 주차 수만으로 계산하지 않습니다. 금주 4번의 직접 확인 결과는 테스트 담당 결과가 나오면 채웁니다.

## 전주까지 개발 현황

```text
활동 찾기, 활동 상세, 활동 만들기, 내 활동, 로그인·회원가입 화면을 구현하고 입력값 오류 표시를 적용하였다. 일반회원과 기관회원 가입 화면을 구분하고 만 14세 미만 가입을 화면에서 제한하였다. 회원 유형, 기관, 관심 분야, 알림, 신고, 이의제기, 제재 등 데이터베이스 테이블을 추가하고 활동 개설 규칙과 위험 단어 목록(차단 15개, 검토 17개)을 정리하였다. 실제 저장과 로그인은 연결 전이었다.
```

## 금주 작업 사항

```text
1. 회원가입·로그인 구현
일반회원과 기관회원의 가입 정보를 실제로 저장하고 JWT 기반 로그인을 구현하였다. 비밀번호는 암호화하여 저장하며, 새로고침해도 로그인이 유지되고 로그아웃하면 로그인 정보가 무효가 된다. 만 14세 미만 가입은 서버에서도 거부하고, 가입 요청에 관리자 권한을 넣어도 일반 회원으로 저장된다. 관심 분야도 함께 저장한다.

2. 역할별 접근 권한 적용
로그인하지 않은 사용자는 활동을 등록할 수 없고, 관리자 확인을 받지 않은 기관회원은 기관 주관 활동을 등록할 수 없도록 서버에서 검사하였다. 관리 화면은 관리자에게만 보이며, 관리자는 기관을 승인하거나 사유를 적어 반려할 수 있다.

3. 활동 개설 저장과 위험도 검사
활동 만들기 화면을 서버와 연결하여 활동을 실제로 저장하였다. 정원(2~10명), 활동 시간(30~180분), 개설 가능 기간과 종료 시각 규칙을 서버에서 다시 검사하고, 위험 단어·분야·종료 시각으로 활동을 바로 공개·관리자 검토·등록 불가로 분류하여 결과를 화면에 표시하였다. 검토 대상 활동은 관리자가 승인하기 전까지 공개되지 않는다.

4. 테스트 및 시연 준비
회원가입·로그인·권한·활동 등록·위험도 분류에 대해 정상 입력과 오류 입력 자동 테스트를 작성하여 서버 25건, 화면 16건을 모두 통과하였다. 테스트 중 저장된 시각이 9시간 밀리는 오류를 발견하여 수정하였다. 시연 인물 11명을 개발 환경에서 로그인 가능한 시연 계정으로 구성하였고, 테스트 담당자가 직접 확인할 항목 20개를 정리하였다(직접 확인 ○건 중 ○건 통과).
```

## 다음주 작업 예정 사항

```text
1. 주변 활동 검색
시연 장소 3곳의 좌표를 확정하여 저장하고, 위치를 기준으로 반경·날짜·분야 검색을 구현하여 가까운 순으로 보여준다.

2. 지도 화면 연동
카카오 지도에 활동 위치를 표시하고 목록과 함께 볼 수 있도록 연결한다.

3. 서버 첫 배포
서버를 인터넷에 배포하고 HTTPS를 적용하여 공개 주소에서 회원가입과 로그인을 할 수 있도록 한다.

4. 검색·배포 테스트
반경 경계, 관리자 검토 전 활동 비공개, 등록 불가 활동 차단, 배포 후 접속을 테스트한다.
```
