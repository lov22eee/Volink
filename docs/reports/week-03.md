# 3주차 진행 보고서 · 복사용

| 항목 | 작성 |
|---|---|
| 조명 | Volink |
| 팀원 | 오준원, 박용빈, 김병수 |
| 프로젝트명 | Volink |
| 작업기간 | 2026.10.13 ~ 2026.10.19 |
| 역할 | 개발 박용빈 / 테스트 김병수 / 확인·발표 오준원 |

개발 진도는 팀이 정해 기입합니다. 주차 수만으로 계산하지 않습니다. 금주 4번의 직접 확인 결과는 테스트 담당 결과가 나오면 채웁니다.

## 전주까지 개발 현황

```text
1. 활동 찾기·상세·만들기·내 활동·로그인·회원가입 화면을 구현하고 입력 오류 표시를 적용하였다.
2. 일반회원과 기관회원 가입 화면을 구분하고 만 14세 미만 가입을 화면에서 제한하였다.
3. 회원·기관·관심 분야·알림·신고·제재 등 DB 테이블과 위험 활동 분류 기준을 정리하였다.
```

## 금주 작업 사항

```text
1. 회원가입 및 로그인 구현
일반회원과 기관회원의 가입 정보를 데이터베이스에 저장하고 JWT 기반 로그인을 구현하였다. 비밀번호는 BCrypt로 단방향 해시하여 저장하고, 새로고침 후에도 로그인이 유지되며 로그아웃 시 로그인 정보가 무효화되도록 하였다. 로그인을 5회 이상 실패하면 1분간 시도를 제한하였다.
2. 역할별 권한 및 관리자 기능 구현
만 14세 미만 가입을 서버에서도 거부하고, 회원가입으로는 관리자 권한을 얻을 수 없도록 하였다. 로그인하지 않은 사용자와 승인받지 않은 기관회원의 활동 등록을 서버에서 차단하였으며, 관리자는 기관 승인·반려와 검토 대상 활동 승인·반려를 처리할 수 있도록 구현하였다. 반려 시에는 사유를 반드시 입력하도록 하였다.
3. 활동 개설 저장 및 위험도 검사 구현
활동 만들기 화면을 서버와 연결하여 활동을 실제로 저장하였다. 정원, 활동 시간, 개설 기간 등 입력 규칙을 서버에서 다시 검사하고, 위험 단어와 활동 분야, 종료 시각을 기준으로 즉시 공개·관리자 검토·등록 불가로 분류하였다. 검토 대상 활동은 관리자가 승인하기 전까지 공개되지 않도록 하였다.
4. 테스트 및 서버 배포
회원가입, 로그인, 권한, 활동 등록, 위험도 분류에 대한 자동 테스트 41건(서버 25건, 화면 16건)을 모두 통과하였다. 또한 매끄러운 시연과 눈으로 직접 확인하는 테스트를 위해 4주차 계획이던 서버 배포를 앞당겨 AWS EC2에 서비스를 배포하고 HTTPS를 적용하여 공개 주소에서 회원가입과 로그인을 할 수 있도록 하였다.
```
