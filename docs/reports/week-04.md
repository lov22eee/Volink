# 4주차 진행 보고서 · 복사용

|---|---|
| 조명 | Volink |
| 팀원 | 오준원, 박용빈, 김병수 |
| 프로젝트명 | Volink |
| 작업기간 | 2026.10.20 ~ 2026.10.26 |
| 역할 | 개발 박용빈 / 테스트 김병수 / 확인·발표 오준원 |

개발 진도는 팀이 정해 기입합니다. 코드는 2026-10-16에 미리 작업했고, 2026-10-21에 장소 검색·화면 개선·1365 연계를 4주차 보완으로 더했습니다.

## 전주까지 개발 현황

```text
1. 회원가입·JWT 로그인을 구현하고 비밀번호를 BCrypt로 단방향 해시하여 저장하였다.
2. 역할별 권한과 관리자의 기관 승인·검토 활동 승인 기능을 구현하였다.
3. 활동 개설을 저장하고 위험 단어·분야·종료 시각으로 공개·검토·등록 불가를 분류하였다.
4. 자동 테스트 41건을 통과하고 AWS EC2에 서비스를 배포하여 HTTPS를 적용하였다.
```

## 금주 작업 사항

```text
1. 장소 좌표 및 공간 인덱스 구성
관리자가 장소의 좌표와 만남 지점을 입력할 수 있도록 하고, 활동 위치를 MySQL의 공간 데이터(POINT)로 저장하여 공간 인덱스를 구성하였다. 좌표를 입력하면 해당 장소의 기존 활동도 함께 위치가 반영되며, 처리 내용은 관리자 조치 기록에 남는다.
2. 주변 활동 검색 구현
사용자 위치를 기준으로 반경(기본 3km)과 날짜, 분야, 활동 유형으로 활동을 검색하여 가까운 순으로 거리와 함께 보여주도록 구현하였다. 공간 인덱스로 후보를 먼저 좁힌 뒤 실제 거리로 다시 걸러내며, 사용자 위치는 검색에만 사용하고 저장하지 않는다.
3. 장소 검색과 장소 분류
활동을 만들 때 카카오 장소 검색이나 지도의 핀으로 실제 장소를 고를 수 있도록 하였다. 공원·카페·도서관 같은 열린 공간은 바로 공개하고, 요양·병원·반려동물·학교 시설은 관리자 검토로, 주유소·술집 등은 고를 수 없도록 분류하였으며, 검색 결과에 서버 서명을 붙여 장소와 분류를 바꿀 수 없게 하였다.
4. 활동 찾기·만들기 화면 개선
활동 찾기에서 위치를 한 번 묻고 지도와 목록을 함께 보여주며, 거리와 대략 이동 시간을 표시하고 주변에 활동이 없으면 반경을 3km에서 20km까지 스스로 넓히도록 하였다. 활동 만들기는 장소 검색 창, 날짜·시작 시간 선택, 22시 전에 끝나는 활동 시간만 보여주는 방식으로 바꾸고, 준비물을 버튼으로 고르면 게시글에 칩으로 표시되도록 하였다.
5. 1365 봉사활동 연계
행정안전부 봉사참여정보서비스(공공데이터)를 연결하여 1365 봉사활동을 같은 지도와 목록에 보여주고, 요약 창에서 내용을 확인한 뒤 신청은 1365로 연결하도록 하였다. 호출 횟수 제한과 캐시를 두고, 담당자 연락처는 저장하지 않는다.
6. 기능 테스트
반경 경계, 검토 전 활동 비공개, 장소 분류, 장소 서명 위조 거부, 1365 응답 처리 등을 자동 테스트하여 서버 53건, 화면 18건을 모두 통과하였다.
```
