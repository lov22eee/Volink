# 4주차 진행 보고서 · 복사용

|---|---|
| 조명 | Volink |
| 팀원 | 오준원, 박용빈, 김병수 |
| 프로젝트명 | Volink |
| 작업기간 | 2026.10.20 ~ 2026.10.26 |
| 역할 | 개발 박용빈 / 테스트 김병수 / 확인·발표 오준원 |

개발 진도는 팀이 정해 기입합니다. 코드는 2026-10-16에 미리 작업해 4주차 발표 뒤 반영합니다.

## 전주까지 개발 현황

```text
1. 회원가입·JWT 로그인을 구현하고 비밀번호를 BCrypt로 단방향 해시하여 저장하였다.
2. 역할별 권한과 관리자의 기관 승인·검토 활동 승인 기능을 구현하였다.
3. 활동 개설을 저장하고 위험 단어·분야·종료 시각으로 공개·검토·등록 불가를 분류하였다.
4. 자동 테스트 41건을 통과하고 AWS EC2에 서비스를 배포하여 HTTPS를 적용하였다.
```

## 금주 작업 사항

```text
1. 장소 좌표 및 공간 인덱스 구성
관리자가 장소의 좌표와 만남 지점을 입력할 수 있도록 하고, 활동 위치를 MySQL의 공간 데이터(POINT)로 저장하여 공간 인덱스를 구성하였다. 좌표를 입력하면 해당 장소의 기존 활동도 함께 위치가 반영되며, 처리 내용은 관리자 조치 기록에 남는다.
2. 주변 활동 검색 구현
사용자 위치를 기준으로 반경(기본 3km)과 날짜, 분야, 활동 유형으로 활동을 검색하여 가까운 순으로 거리와 함께 보여주도록 구현하였다. 공간 인덱스로 후보를 먼저 좁힌 뒤 실제 거리로 다시 걸러내며, 사용자 위치는 검색에만 사용하고 저장하지 않는다.
3. 지도 화면 연동
활동 찾기에 '내 주변 찾기'와 반경 선택, 지도 보기를 추가하였다. 위치 권한을 거부하면 활동 장소 중심을 기준으로 검색하며, 카카오 지도 키를 등록하면 지도에 장소와 검색 반경을 표시하도록 연결하였다.
4. 검색 기능 테스트
반경 3km 기준 2.9km 활동은 포함되고 3.4km 활동은 제외되는지, 관리자 검토 전 활동이 검색에 나오지 않는지 등을 자동 테스트하여 서버 29건, 화면 17건을 모두 통과하였다.
```
