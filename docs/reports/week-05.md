| 작업기간 | 2026.10.27 ~ 2026.11.02 |
| 역할 | 개발 박용빈 / 테스트 김병수 / 확인·발표 오준원 |

개발 진도는 팀이 정해 기입합니다. 코드는 2026-10-16에 미리 작업해 5주차 발표 뒤 반영합니다.

## 전주까지 개발 현황

```text
1. 회원가입·JWT 로그인, 역할별 권한, 활동 개설과 위험도 검사를 구현하였다.
2. 관리자가 장소 좌표를 입력하고 활동 위치를 공간 인덱스로 관리하도록 구성하였다.
3. 사용자 위치 기준 반경·날짜·분야 검색과 지도 보기를 구현하였다.
4. AWS EC2에 서비스를 배포하고 HTTPS를 적용하였다.
```

## 금주 작업 사항

```text
1. 참가 신청 및 승인 구현
참가자가 활동에 신청하면 모집자가 신청자 목록에서 승인하거나 거절하도록 구현하였다. 같은 활동 중복 신청, 자기 활동 신청, 관리자 신청은 서버에서 막으며, 신청자 목록은 모집자 본인만 볼 수 있고 이름 일부만 보이도록 하였다.
2. 정원 잠금 및 대기열 구현
승인할 때 활동 행을 잠근 뒤 확정 인원을 다시 세어 정원을 넘지 않도록 하였다. 정원이 차면 이후 신청자에게 대기 순번을 부여하고, 확정자가 취소하면 대기 1순위에게 자리를 제안하여 제한시간(6시간 또는 1시간) 안에 수락하면 확정되도록 하였다.
3. 자동 만료 처리 및 알림 구현
1분마다 응답 시간이 지난 자리 제안을 만료시키고 다음 순번에게 넘기며, 활동 시작 2시간 전에는 대기열을 마감하도록 하였다. 신청·확정·거절·자리 제안·만료는 화면 안 알림으로 알리고, 모든 상태 변경을 기록으로 남겼다.
4. 동시성 테스트 및 오류 수정
마지막 1자리에 10건의 승인을 동시에 보내는 테스트에서 모두 확정되는 오류를 발견하여, 트랜잭션 격리 수준을 조정해 1건만 확정되도록 수정하였다. 신청·대기·만료 등 자동 테스트를 추가하여 서버 36건, 화면 18건을 모두 통과하였다.
```

## 다음주 작업 예정 사항

```text
1. 모집자가 60초마다 바뀌는 QR 코드를 띄우고 참가자가 스캔해 체크인하도록 한다.
2. 체크인 시 활동 시간과 장소 반경(200m)을 서버에서 함께 확인한다.
3. QR을 쓸 수 없는 경우 모집자가 사유를 적어 수동으로 출석을 확인하도록 한다.
4. 활동 종료 후 모집자 완료 확인으로 활동 기록을 만들고 불참자는 노쇼로 처리한다.
```
