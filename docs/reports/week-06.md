# 6주차 진행 보고서 · 복사용

| 항목 | 작성 |
|---|---|
| 조명 | Volink |
| 팀원 | 오준원, 박용빈, 김병수 |
| 프로젝트명 | Volink |
| 작업기간 | 2026.11.03 ~ 2026.11.09 |
| 역할 | 개발 박용빈 / 테스트 김병수 / 확인·발표 오준원 |

개발 진도는 팀이 정해 기입합니다. 코드는 2026-10-16에 미리 작업해 6주차 발표 뒤 반영합니다.

## 전주까지 개발 현황

```text
1. 회원가입·로그인, 활동 개설·위험도 검사, 관리자 검토를 구현하였다.
2. 반경·날짜·분야로 주변 활동을 찾는 위치 검색과 지도 보기를 구현하였다.
3. 참가 신청·승인과 정원 잠금, 대기열 자리 제안, 화면 안 알림을 구현하였다.
4. AWS EC2에 서비스를 배포하고 HTTPS를 적용하였다.
```

## 금주 작업 사항

```text
1. 출석 QR 구현
모집자 화면에 1분마다 바뀌는 출석 QR을 표시하도록 하였다. QR에는 활동 번호와 발급 시각을 서버 비밀키로 서명한 값이 들어가며 60초가 지나면 사용할 수 없다. 참가자가 휴대폰 카메라로 찍으면 체크인 화면이 열린다.
2. 시간·위치 체크인 구현
체크인 시 서버가 참가 확정 여부, 체크인 허용 시간(시작 30분 전~시작 후 30분), QR 서명과 유효시간, 활동 장소 200m 이내인지를 함께 확인한다. 위치 좌표는 거리 계산에만 사용하고 저장하지 않으며, 위치를 확인할 수 없으면 모집자가 사유를 적어야만 수동으로 출석을 확인할 수 있다.
3. 완료 확인 및 활동 기록 구현
활동이 끝난 뒤 모집자가 출석한 참가자만 완료를 확인할 수 있게 하고, 확인 즉시 활동 기록과 알림이 만들어지도록 하였다. 스케줄러가 활동 시작·종료 상태를 바꾸고, 체크인하지 않은 확정자는 불참으로 기록한다.
4. 개설부터 완료까지 흐름 테스트
시간 밖 체크인, 만료·위조 QR, 반경 밖 체크인, 사유 없는 수동 확인, 체크인 없는 완료를 서버가 막는지 자동 테스트하고, 개설→신청→승인→체크인→완료 전체 흐름을 화면 테스트로 확인하여 서버 41건, 화면 19건을 모두 통과하였다.
```

## 다음주 작업 예정 사항

```text
1. 참가자·모집자가 문제를 신고하고 증빙 파일을 올리면 관리자가 처리하도록 한다.
2. 활동 기록에 대해 7일 안에 이의를 신청하고 관리자가 판단하도록 한다.
3. 노쇼가 쌓이면 신청을 제한하고 관리자가 사유와 함께 제재할 수 있도록 한다.
4. 관심 분야·거리·시간을 반영한 활동 추천을 구현한다.
```
