# 6주차 진행 보고서 · 복사용

| 항목 | 작성 |
|---|---|
| 조명 | Volink |
| 팀원 | 오준원, 박용빈, 김병수 |
| 프로젝트명 | Volink |
| 작업기간 | 2026.11.03 ~ 2026.11.09 |
| 역할 | 개발 박용빈 / 테스트 김병수 / 확인·발표 오준원 |

개발 진도는 팀이 정해 기입합니다. 6주차 코드는 2026-10-16에 브랜치에서 먼저 만들었고, 2026-11-03에 지금 main(5주차 최종본·2.0 화면) 위로 옮기면서 화면을 새로 만들고 기능을 보강했습니다.

## 전주까지 개발 현황

```text
- 참가 신청·모집자 승인·거절, 정원 초과 방지, 대기 순번과 빈자리 제안, 자동 만료를 구현함.
- 신청 결과와 빈자리 제안을 사이트 내부 알림으로 안내하고 상태 변경 내역을 기록함.
- 홈·활동 찾기·상세 화면을 정리하고 로그인 후 홈에서 내 활동 현황을 확인하도록 함.
```

## 금주 작업 사항

```text
1. 출석 QR 및 체크인
모집자 화면에 30초마다 바뀌는 출석 QR을 표시하고, 참가자가 휴대폰 카메라로 찍으면 체크인 화면이 열리도록 함. 서버가 참가 확정 여부, 체크인 시간(시작 30분 전~시작 후 30분), QR 서명·유효시간(60초), 활동 장소 200m 이내인지를 함께 확인하며 위치 좌표는 저장하지 않음.

2. 수동 확인 및 활동 완료
위치를 확인할 수 없는 참가자는 모집자가 사유를 골라 수동으로 출석을 확인하도록 함. 활동이 끝나면 체크인한 참가자를 한 번에 완료 처리하고, 완료되면 참가자의 활동 기록이 만들어지며 체크인하지 않은 확정자는 불참으로 처리함.

3. 활동 자동 진행 및 안내
시작 버튼 없이 서버가 시간에 맞춰 체크인 열림·활동 시작·종료를 처리함. 시작 24시간 전 승인 대기 안내, 체크인 열림 안내, 시작 시 마감된 신청 안내를 사이트 내부 알림으로 보냄.

4. 테스트 및 오류 수정
체크인한 사람이 정원에서 빠지던 오류를 찾아 수정함. 시간 밖·만료·위조 QR, 반경 밖, 사유 없는 수동 확인, 종료 전 완료를 서버가 막는지 확인하고, QR 체크인부터 활동 기록까지 화면 흐름을 자동 테스트함(서버 85건, 화면 23건 통과).
```

## 다음주 작업 예정 사항

```text
1. 모집자가 사유를 적고 활동을 취소하거나 일정을 바꾸면 신청자에게 알림이 가도록 한다.
2. 참가자·모집자가 문제를 신고하고 증빙 사진을 올리면 관리자가 처리하도록 한다.
3. 활동 기록에 대해 7일 안에 이의를 신청하고, 노쇼가 쌓이면 신청을 제한하도록 한다.
4. 관심 분야·거리·시간을 반영한 활동 추천을 구현한다.
```
