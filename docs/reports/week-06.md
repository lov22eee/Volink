# 6주차 진행 보고서 · 복사용

| 항목 | 작성 |
|---|---|
| 조명 | Volink |
| 팀원 | 오준원, 박용빈, 김병수 |
| 프로젝트명 | Volink |
| 작업기간 | 2026.11.03 ~ 2026.11.09 |
| 역할 | 개발 박용빈 / 테스트 김병수 / 확인·발표 오준원 |

개발 진도는 팀이 정해 기입합니다. 6주차 코드는 2026-10-16에 브랜치에서 먼저 만들었고, 2026-11-03에 지금 main(5주차 최종본·2.0 화면) 위로 옮기면서 화면을 새로 만들고 기능을 보강했습니다.

## 전주까지 개발 현황

```text
- 참가 신청·모집자 승인·거절, 정원 초과 방지, 대기 순번과 빈자리 제안, 자동 만료를 구현함.
- 신청 결과와 빈자리 제안을 사이트 내부 알림으로 안내하고 상태 변경 내역을 기록함.
- 홈·활동 찾기·상세 화면을 정리하고 로그인 후 홈에서 내 활동 현황을 확인하도록 함.
```

## 금주 작업 사항

```text
1. 출석 QR 및 체크인
모집자 화면에 30초마다 바뀌는 출석 QR을 표시하고, 참가자가 휴대폰 카메라로 찍으면 체크인 화면이 열리도록 함. 서버가 참가 확정 여부, 체크인 시간(시작 30분 전~시작 후 30분), QR 서명·유효시간(60초), 활동 장소 200m 이내인지를 함께 확인하며 위치 좌표는 저장하지 않음.

2. 수동 확인 및 활동 완료
위치를 확인할 수 없는 참가자는 모집자가 사유를 골라 수동으로 출석을 확인하도록 함. 활동이 끝나면 체크인한 참가자를 한 번에 완료 처리하고, 완료되면 참가자의 활동 기록이 만들어지며 체크인하지 않은 확정자는 불참으로 처리함.

3. 활동 소식(공지·Q&A)
모집자가 공지를 올리고 참가 확정자가 질문하면 모집자가 답변하도록 하여, 연락처를 공유하지 않고 서비스 안에서 소통하도록 함. 전화번호·이메일·오픈채팅 링크는 올릴 수 없게 막고 공지·질문·답변은 사이트 내부 알림으로 전달함.

4. 활동 자동 진행 및 안내
시작 버튼 없이 서버가 시간에 맞춰 체크인 열림·활동 시작·종료를 처리함. 시작 24시간 전 승인 대기 안내, 체크인 열림 안내, 시작 시 마감된 신청 안내를 사이트 내부 알림으로 보냄.

5. 모집자 활동 취소·일정 변경과 참가자 알림
모집자가 사유를 적고 활동을 취소하거나 일정을 한 번(시작 24시간 전까지) 바꾸면 신청자 모두에게 사이트 내부 알림이 가도록 함. 참가자는 ‘늦어요(10·20·30분)’, ‘못 가요(이유 선택)’로 모집자에게 알리고, 하루 전에는 ‘내일 함께해요’ 알림을 받음. 활동 강도·실내외·처음 환영 표시와 저장한 봉사를 추가함.

6. 앱(APK) 전용 화면
PC 웹 화면은 그대로 두고, 안드로이드 앱에 넣을 휴대폰 전용 화면을 따로 만듦. 로그인 필수 첫 화면, 3단계 회원가입(기관 가입은 PC), 하단 탭 5개(홈·찾기·모집·내 활동·마이), 상태별 활동 상세, 모집자 대시보드, 3단계 활동 만들기, 키보드가 올라와도 입력칸이 보이도록 처리함.

7. 테스트 및 오류 수정
체크인한 사람이 정원에서 빠지던 오류를 찾아 수정함. 시간 밖·만료·위조 QR, 반경 밖, 사유 없는 수동 확인, 종료 전 완료를 서버가 막는지 확인하고, QR 체크인부터 활동 기록까지, 앱의 가입·만들기·신청·승인·일정 변경·취소 흐름을 자동 테스트함(서버 99건, 화면 27건 통과).

8. 안드로이드 앱(APK) 테스트 빌드
앱 화면을 Capacitor로 안드로이드 앱에 넣고, 앱 아이콘(잎 로고)과 시작 화면을 만듦. 앱에서도 로그인이 유지되도록 서버가 앱 주소에서 온 요청에만 접속을 허용하고 로그인 유지 값을 앱이 보관하도록 함. 카카오·구글 로그인은 휴대폰 브라우저에서 진행한 뒤 앱으로 돌아오게 하고, 출석 QR은 앱 안 카메라로 읽도록 함. APK는 GitHub Actions에서 자동으로 만들어 내려받을 수 있게 함.
```

## 다음주 작업 예정 사항

```text
1. 테스트용 APK를 실제 휴대폰에 설치해 키보드·카메라 QR·위치·카카오/구글 로그인을 확인한다.
2. 참가자·모집자가 문제를 신고하고 증빙 사진을 올리면 관리자가 처리하도록 한다.
3. 활동 기록에 대해 7일 안에 이의를 신청하고, 노쇼가 쌓이면 신청을 제한하도록 한다.
4. 관심 분야·거리·시간을 반영한 활동 추천을 구현한다.
```
