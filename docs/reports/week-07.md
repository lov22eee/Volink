개발 진도는 팀이 정해 기입합니다. 코드는 2026-10-16에 미리 작업해 7주차 발표 뒤 반영합니다.

## 전주까지 개발 현황

```text
1. 회원가입·로그인, 활동 개설·위험도 검사, 위치 검색과 지도를 구현하였다.
2. 참가 신청·승인, 정원 잠금, 대기열 자리 제안, 화면 안 알림을 구현하였다.
3. QR·시간·위치 체크인과 수동 확인, 완료 확인·활동 기록, 노쇼 처리를 구현하였다.
4. AWS EC2에 서비스를 배포하고 HTTPS를 적용하였다.
```

## 금주 작업 사항

```text
1. 신고 및 증빙 업로드 구현
활동에 참여한 사람만 활동이나 함께한 사람을 신고할 수 있게 하고, 증빙 파일(jpg·png·pdf, 10MB, 최대 3개)을 올리도록 하였다. 파일의 실제 형식을 내용으로 확인하고 사진은 다시 저장하여 위치 정보(EXIF)를 지웠으며, 파일은 비공개 폴더에 보관하고 관리자만 5분 동안 유효한 서명 링크로 열람하도록 하였다.
2. 관리자 신고 처리 및 이의 신청 구현
관리자가 사유를 적고 신고 대상의 출석·기록을 보류하거나, 조치 없이 종료하거나, 기록을 무효로 할 수 있도록 하였다. 완료 기록에 대해서는 7일 안에만 이의를 신청할 수 있으며, 이의가 들어오면 기록이 보류되고 관리자가 인정 또는 기각한다.
3. 제재 및 추천 구현
관리자가 사유와 기간을 정해 경고·이용 제한·이용 정지를 줄 수 있게 하고, 최근 90일 노쇼가 3회이면 14일간 신청이 자동으로 제한되도록 하였다. 또한 관심 분야·거리·일정을 점수로 합산하여 사용자에게 맞는 활동을 이유와 함께 추천하도록 하였다.
4. 백업 및 회귀 테스트
매일 데이터베이스와 증빙 파일을 7일치 보관하는 백업을 만들고 실제로 복원되는지 확인하였다. 신고·이의 신청·제재·추천 자동 테스트를 추가하여 서버 47건, 화면 20건을 모두 통과하였으며, 테스트 중 가끔 로그인이 풀리던 원인을 찾아 수정하였다.
```
