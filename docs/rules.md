화면 선택지(2026-10-21 보완): 날짜는 내일~60일 뒤만, 시작 시간은 06:00~21:30·10분 단위 굴리는 선택, 활동 시간은 30분~3시간·10분 단위 중 **22:00 전에 끝나는 것만** 보여 줍니다(시작을 늦추면 맞는 가장 긴 길이로 자동 조정). 정원은 2~10명 드롭다운. 그래서 화면에서는 시간 오류가 나지 않고, 서버는 같은 규칙을 그대로 다시 검사합니다. 24시간 규칙은 내일 이른 시간을 고르면 화면에서 안내합니다.

위험 단어(2026-10-21 보완 2): 제목·소개·준비물에서 **띄어쓰기를 무시하고** 찾습니다(‘전기 배관’, ‘전기배관’ 모두). 추가: 등록 불가 배관·전선·고압·용접, 관리자 검토 전기·가스. 단어 검사는 보조 수단이며 빠뜨릴 수 있습니다.

수정·삭제: 모집자만, 시작 전, 공개(RECRUITING)·검토 중(DRAFT)일 때. 신청자가 있으면 소개·만나는 곳만 고칠 수 있고 삭제 불가. 수정해도 위험도 검사를 다시 합니다.

## 장소 분류 (2026-10-21 · `PlaceClassifier.java`)

Kakao 장소의 카테고리(위험 단어는 장소 이름도)로 정합니다. 위에서부터 처음 맞는 줄이 이깁니다. 모르는 종류는 **검토**입니다(확인 없이 공개하지 않음).

| 결과 | 종류(예시 단어) | 처리 |
|---|---|---|
| 고를 수 없음 | 주유소·충전소·LPG, 술집·주점·호프·유흥·나이트·단란, 모텔·여관, 사격·카지노·성인용품·군부대·교도소·공사현장 | 검색 결과에 ‘고를 수 없음’, 서명 없음 |
| 검토 후 공개 | Kakao 종류로 알 수 없는 장소만 | 위험도 REVIEW(관리자 승인 전 비공개) |
| 바로 공개 | 공원·광장·산책로·둘레길·하천, 도서관·문화·박물관, 공공기관·행정복지센터·시청·자원봉사센터, 관광명소, 카페, 음식점, 운동장·체육시설, 그리고 2026-10-25부터 요양·복지시설, 병원·약국, 반려동물 시설, 학교·어린이집, 종교시설, 아파트·숙박, 물가·산업시설 | 다른 검사(위험 단어·일몰·분야)만 적용 |

**2026-10-25 사용자 결정:** 이름이 있는 장소는 대부분 사람이 많은 공공장소이고, 위험한 활동은 활동 이름·소개·분야(예: 어르신·돌봄 → 검토, 사다리 → 등록 불가)에서 따로 걸러지므로 장소 검토는 ‘모르는 장소’만 남겼습니다. 장소 이름표(요양·복지시설 등)는 그대로 보여줍니다.

관리자 등록 장소 3곳은 공원(바로 공개)입니다. 분류는 위험 가능성을 고르는 보조 수단이며 현장이 안전하다는 보증이 아닙니다.

가정(인수인계에 기록): 24시간 전 개설은 REVIEW 검토 시간 확보, 22:00 상한은 운영 기준. 계획서상 **일몰 이후 종료는 차단이 아니라 REVIEW**이므로, 22:00 전이어도 일몰 뒤 끝나면 서버 위험도 검사에서 REVIEW로 분류합니다(3주차).

## 오류 표시 방식

1. 제출 시 모든 칸 검사 → 칸 아래 빨간 문구 + 칸 테두리 강조(`aria-invalid`).
2. 버튼 위에 “입력 내용을 확인해 주세요. 고칠 항목 N개”(`role=alert`).
3. 첫 번째 틀린 칸으로 커서 이동.
4. 서버 오류는 같은 자리에 `fieldErrors`로 표시([api.md](api.md#오류-응답)).

## 위험 활동 분류

검사 순서(계획서 6.7): **명확한 금지 규칙 → 위험 키워드 → REVIEW는 관리자 최종 확인**. 키워드 검사는 보조 수단이며 활동이 안전하다고 보증하지 않습니다.

| 등급 | 처리 | 금지 규칙 | 키워드 초안 (`risk_keywords`, V3) |
|---|---|---|---|
| BLOCKED (15) | 게시 거부 | 정원 2~10·180분 위반, 22:00 이후 종료 | 사다리, 고소작업, 지붕, 전기 작업, 가스 작업, 전기톱, 예초기, 농약, 화학약품, 입수, 의료, 주사, 모금, 후원금, 음주 |
| REVIEW (17) | 관리자 승인 전 비공개 | 분야 base_risk=REVIEW(지역 돌봄), 일몰 이후 종료 | 어르신, 어린이, 아동, 동물, 시설, 가정 방문, 야간, 일몰, 차도, 운전, 하천, 등산, 낫, 칼, 조리, 무거운, 공사 |
| LOW | 즉시 게시 | 위에 해당 없음 | - |

일몰 시각은 서울 기준 월별 근사값(`RiskClassifier.SUNSET`)이며 지역·날짜별 정확한 값이 아닙니다. 검사 순서: 등록 불가 단어가 하나라도 있으면 BLOCKED → 아니면 검토 단어·검토 분야·일몰 후 종료 중 하나라도 있으면 REVIEW → 나머지 LOW.

알려진 한계: ‘칼’은 ‘칼국수’처럼 엉뚱한 글자에도 걸립니다(REVIEW로 넘어가 관리자가 판단). 3주차에 실제 문장으로 오탐을 시험하고 목록을 조정합니다.
