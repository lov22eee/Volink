# 입력·오류·위험 규칙 · 2주차

2026-10-11 확정. 화면 코드는 `frontend/src/rules.ts`. **서버도 3주차에 같은 규칙으로 다시 검사합니다**(화면 검사만으로는 막지 못함).

## 활동 만들기

| 칸 | 규칙 | 오류 문구 |
|---|---|---|
| 활동 이름 | 5~100자 | 활동 이름은 5~100자로 입력해 주세요. |
| 장소 | 필수 | 장소를 선택해 주세요. |
| 활동 날짜 | 시작이 지금부터 24시간 이후 ~ 60일 이내 | 활동은 지금부터 24시간 이후로 정해 주세요. / 활동은 60일 이내로 정해 주세요. |
| 시작 시간 | 06:00 이후 시작, 22:00 전 종료 | 시작 시간은 06:00 이후로 정해 주세요. / 활동은 22:00 전에 끝나야 합니다. |
| 모집 정원 | 정수 2~10명 (모집자 제외) | 모집 정원은 2~10명입니다. |
| 활동 시간 | 정수 30~180분 | 활동 시간은 30~180분입니다. |
| 활동 소개 | 20~2000자 | 활동 소개는 20~2000자로 적어 주세요. |
| 안전 안내 | 두 항목 모두 확인 | 안전 안내 두 항목을 모두 확인해 주세요. |
| 활동 유형 | 기관 주관은 확인된 기관회원만 | 버튼 비활성 + 안내 |

가정(인수인계에 기록): 24시간 전 개설은 REVIEW 검토 시간 확보, 22:00 상한은 운영 기준. 계획서상 **일몰 이후 종료는 차단이 아니라 REVIEW**이므로, 22:00 전이어도 일몰 뒤 끝나면 서버 위험도 검사에서 REVIEW로 분류합니다(3주차).

## 회원가입·로그인

| 칸 | 규칙 | 오류 문구 |
|---|---|---|
| 이름 | 1~40자 | 이름을 1~40자로 입력해 주세요. |
| 생년월일 | 한국 날짜 기준 **만 14세 이상** | 만 14세 미만은 가입할 수 없습니다. |
| 관심 분야 | 1~3개 | 관심 분야를 1~3개 골라 주세요. |
| 기관명 (기관회원) | 2~100자 | 기관명을 2~100자로 입력해 주세요. |
| 기관 연락처 (기관회원) | 숫자·하이픈 9~20자, 다른 회원에게 공개 안 함 | 연락처는 숫자와 - 로 9~20자 입력해 주세요. |
| 이메일 | 형식, 254자 이하 | 이메일 형식을 확인해 주세요. |
| 비밀번호 | 8~72자, 영문+숫자 포함 | 비밀번호는 영문과 숫자를 섞어 8~72자로 입력해 주세요. |
| 비밀번호 확인 | 일치 | 비밀번호가 일치하지 않습니다. |
| 이용 안내 | 확인 필수 | 이용 안내를 확인해 주세요. |
| 회원 유형 | 일반·기관 두 가지만, 관리자 없음 | - |

만 14세 미만 제한 이유: 법정대리인 동의 절차를 만들지 않음(계획서 6.3). 로그인 실패는 “이메일 또는 비밀번호가 올바르지 않습니다”처럼 어느 쪽이 틀렸는지 알려주지 않습니다(3주차).

## 오류 표시 방식

1. 제출 시 모든 칸 검사 → 칸 아래 빨간 문구 + 칸 테두리 강조(`aria-invalid`).
2. 버튼 위에 “입력 내용을 확인해 주세요. 고칠 항목 N개”(`role=alert`).
3. 첫 번째 틀린 칸으로 커서 이동.
4. 서버 오류는 같은 자리에 `fieldErrors`로 표시([api.md](api.md#오류-응답)).

## 위험 활동 분류

검사 순서(계획서 6.7): **명확한 금지 규칙 → 위험 키워드 → REVIEW는 관리자 최종 확인**. 키워드 검사는 보조 수단이며 활동이 안전하다고 보증하지 않습니다.

| 등급 | 처리 | 금지 규칙 | 키워드 초안 (`risk_keywords`, V3) |
|---|---|---|---|
| BLOCKED (15) | 게시 거부 | 정원 2~10·180분 위반, 22:00 이후 종료 | 사다리, 고소작업, 지붕, 전기 작업, 가스 작업, 전기톱, 예초기, 농약, 화학약품, 입수, 의료, 주사, 모금, 후원금, 음주 |
| REVIEW (17) | 관리자 승인 전 비공개 | 분야 base_risk=REVIEW(지역 돌봄), 일몰 이후 종료 | 어르신, 어린이, 아동, 동물, 시설, 가정 방문, 야간, 일몰, 차도, 운전, 하천, 등산, 낫, 칼, 조리, 무거운, 공사 |
| LOW | 즉시 게시 | 위에 해당 없음 | - |

알려진 한계: ‘칼’은 ‘칼국수’처럼 엉뚱한 글자에도 걸립니다(REVIEW로 넘어가 관리자가 판단). 3주차에 실제 문장으로 오탐을 시험하고 목록을 조정합니다.
