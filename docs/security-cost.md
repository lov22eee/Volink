# 보안·비용 기준 · 2주차

2026-10-11 정한 **기준**입니다. 아직 적용·배포하지 않았습니다. 금액은 확인한 견적이 아니라 판단 기준이며, 실제 요금은 4주차 배포 전에 AWS 콘솔의 요금 계산기로 확인해 기록합니다.

## 보안 기준

| 영역 | 기준 | 적용 주차 |
|---|---|---|
| 비밀번호 | BCrypt(강도 10 이상) 단방향 해시, 원문·해시를 로그에 남기지 않음 | 3 |
| 토큰 | Access JWT 30분(HS256, 서버 환경변수 비밀키 32바이트 이상), Refresh 14일 HttpOnly·Secure·SameSite=Strict 쿠키, 로그아웃 시 폐기 | 3 |
| 권한 | 역할 + **소유관계**(organizer_id, user_id, 기관 상태)를 서버에서 확인. 남의 자료는 404 | 3~7 |
| 관리자 | 가입으로 만들 수 없음. 모든 조치는 사유 필수, `admin_actions`에 기록 | 3, 7 |
| 입력 | 서버에서 [rules.md](rules.md) 재검사, SQL은 파라미터 바인딩만 | 3 |
| 요청 제한 | 로그인 5회/분/IP, 가입·신고 10회/시간/계정 → 429 | 3, 7 |
| 위치 | 검색·체크인 순간만 사용, 좌표 원문 저장·로그 금지, 체크인은 반경 안/밖과 시각만 | 4, 6 |
| 연락처 | 다른 회원에게 공개 안 함, 기관 연락처는 관리자만 | 3 |
| QR | 활동 번호+발급 시각을 서버 비밀키로 서명, 60초 유효. 완벽한 부정 방지는 아님 | 6 |
| 파일 | jpeg·png·pdf, 10MB, 최대 3개, 실제 형식 검사, EXIF 위치 제거, 비공개 S3, 5분 제한 URL | 7 |
| 비밀값 | `.env`·서버 환경변수로만 관리, Git·화면 코드(VITE_)에 넣지 않음. Kakao JS 키는 도메인 제한 | 계속 |
| 통신 | Nginx + Let’s Encrypt HTTPS, HTTP는 HTTPS로 이동, CORS는 서비스 도메인만 | 4 |
| DB | 앱 계정은 해당 DB 권한만, 3306 외부 공개 금지, 매일 백업 7일 보관 | 4, 7 |
| 로그 | 비밀번호·토큰·좌표·연락처 미기록 | 계속 |

## 비용 기준

| 항목 | 선택 | 기준 |
|---|---|---|
| 서버 | EC2 1대(Ubuntu)에 Nginx + Spring Boot + MySQL | 프리 티어·학생 크레딧 범위 안 소형 인스턴스. RDS는 쓰지 않음(비용) |
| 저장소 | S3 버킷 1개(비공개), 증빙·DB 백업 | 수명 주기로 백업 30일 후 삭제 |
| 도메인·인증서 | 무료 인증서(Let’s Encrypt) | 도메인 구매는 팀 결정 |
| 지도 | Kakao 지도 Web API | 무료 사용량 안에서, 키 도메인 제한 |
| 알림 | 화면 안 알림(DB 조회) | 문자·메일·푸시 비용 없음 |
| 화면 미리보기 | GitHub Pages | 무료 |
| 안전장치 | AWS 예산 알림 설정, 시연 끝나면 인스턴스 중지 | 4주차 배포 전에 설정 |

**정할 것(팀):** 월 예산 상한, 도메인 구매 여부, 학생 크레딧 사용 가능 여부.
