## 공개 화면에서 제거한 것

졸업작품·학교·팀원 소개, 주차 배지, 발표 메뉴와 슬라이드, 개발 현황, 사용자 권한표, 시연 페르소나 집계, API·DB 상태, 위험도 내부 처리표를 제거했습니다. ERD·권한·진행 상황·검증 결과·인수인계는 README와 docs에서 관리합니다. 기존 발표 HTML은 `docs/archive/`에 보관하며 프론트의 public 디렉터리에서 제외했습니다.

## 실제 기능과 남은 기능

지금 동작하는 것은 예시 데이터 조회와 UI 탐색·필터·입력 확인입니다. 인증, 회원가입 처리, 기관 확인·승인, 활동 저장, 신청·승인·대기열, 지도·위치 검증, 체크인·완료·신고 기능은 아직 연결되지 않았습니다. 내 활동에 임의의 개인 기록을 표시하지 않습니다. 공개 HTML에는 활동·장소의 필요한 필드만 포함하고 페르소나와 내부 장소 검증 메모를 제외했습니다.

일반 서비스 형태를 유지하면서도 하단의 짧은 미리보기 안내와 동작하지 않는 기능의 버튼·설명을 통해 사용자가 실제 모집·인증으로 오해하지 않도록 했습니다. 공식 실적·보험 비적용 안내를 유지했습니다.

## 검증 결과

- `frontend/`의 `npm run ui:export`: TypeScript 검사·Vite 빌드·공개용 단일 HTML 생성 성공.
- `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e`: **11개 통과**. 서비스 검증 9개(공개 HTML 1개 포함), 보관된 발표 자료 검증 2개입니다.

- 공개 HTML은 모든 네트워크 요청을 차단한 브라우저에서 6개 화면을 확인했습니다. 외부 요청·브라우저 오류 0건. 학교·주차·발표·내부 데이터 미포함을 확인했습니다.
- `./scripts/check-dev.sh`: 기존 Vite→Spring Boot→MySQL의 읽기 API 연결 통과. 백엔드·DB 코드는 변경하지 않았습니다. 과거의 백엔드 테스트 8개 결과를 이번 실행 결과로 재기록하지 않습니다.
- 초기 검증에서 선택 입력의 접근성 이름과 부드러운 스크롤 완료 시점 문제를 발견해 수정한 뒤 위 테스트를 모두 통과했습니다.
