# 제출 보고서 발표 자료 검증

검증일: 2026-10-07, 한국 기준. 기준 문서: 사용자가 이미 제출한 20261006 HWP(작업기간 2026.09.28~10.05).

## 완료

- 제출본의 금주 4항목과 다음주 4항목을 7장 슬라이드로 구성했습니다.
- 일반회원·기관회원·관리자, 기관 승인, 6개 UI 화면을 발표용 설계 시안으로 표시했습니다.
- 실제 인증·기관 승인·활동 신청 기능을 구현 완료로 설명하지 않았습니다.
- 이전에 만든 1주차 실행 발표와 제출 보고서 발표를 별도 메뉴로 구분했습니다.
- 원본 HWP와 기존 API·DB·마이그레이션을 변경하지 않았습니다.

## 신규 테스트 범위

1. 네트워크 요청을 차단한 페이지에 HTML 전체를 직접 로드하고 외부 HTTP 요청이 없음을 확인했습니다. 7장 이동, 키보드, 대본, 처음·끝 이동, 인쇄 모드 전체 슬라이드 노출을 검증했습니다.
2. 서비스가 제공하는 발표 HTML 경로에서 6개 UI 시안 전환, 기관 승인 대기 표시, 390px 모바일 가로 넘침 없음과 표지 복귀를 검증했습니다.

클라우드 관리 브라우저는 `file://` 탐색을 정책상 차단합니다. 이를 변경하지 않고, 허용된 파일 읽기로 자체 제작 HTML 내용을 로드해 서버·인터넷 의존성이 없는 실행을 검증하고 PDF를 생성했습니다. 개인 PC의 파일 더블클릭 실행은 이 클라우드에서 직접 검증한 항목이 아닙니다.

기존 프론트 빌드·브라우저 테스트·API 연결을 확인했습니다. 백엔드 코드를 바꾸지 않아 이번 변경에서는 MySQL 통합 테스트를 다시 실행하지 않았습니다. 앞선 1주차 검증 결과는 별도 문서에 유지합니다.
