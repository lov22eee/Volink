## 발견·수정

- **저장 시각이 9시간 밀림:** 10:00으로 만든 활동이 19:00으로 보이는 것을 화면 캡처에서 발견했습니다. JVM 시간대(UTC)에서 `Timestamp.valueOf`가 시각을 변환한 것이 원인입니다. `LocalDateTime`을 그대로 넘기도록 고치고, 백엔드·화면 테스트에 ‘입력한 시각 그대로’ 확인을 추가했습니다.
- **화면 테스트 경쟁 상태:** 로그아웃 직후 로그인 화면으로 이동하면 로그아웃 처리 후 이동이 덮어써 실패했습니다. 테스트에서 로그아웃 완료를 기다리도록 고쳤습니다(서비스 코드 문제 아님).
- 화면 테스트가 개발 DB에 남긴 확인용 계정·활동(`@example.com`)을 캡처 전에 정리했습니다. 시연 계정 11명은 유지했습니다.
- Maven 프록시 포트가 세션마다 바뀌어 `./scripts/configure-cloud.sh`를 다시 실행했습니다(클라우드 환경 한정).
