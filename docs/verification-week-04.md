## 발견·수정

- 지도 보기 테스트가 장소 이름 버튼과 새 지도 핀을 동시에 찾아 실패했습니다. 장소 목록 버튼만 찾도록 테스트를 좁혔습니다(서비스 코드 문제 아님).
- 화면 테스트가 3주차 캡처를 덮어쓰고 있어, 캡처 파일 이름을 주차별(`week-04-*`)로 바꾸고 3주차 캡처는 원래대로 두었습니다.

## 실행하지 않은 것

- Kakao 지도 표시: 키가 없어 실제 지도는 확인하지 못했습니다(키가 없을 때의 위치 그림만 확인).
- 실제 장소 좌표: 아직 입력하지 않았습니다. 테스트 좌표는 시험용이며 실제 위치가 아닙니다.
- 배포 서버 반영·‘첫 배포 검증’: main 병합 후 `server-setup.sh`를 실행해야 합니다.
- 테스트 담당 직접 확인([목록](manual-test-week04.md)): 아직 결과 없음.
