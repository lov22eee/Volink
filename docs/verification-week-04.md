## 발견·수정 (보완)

- 장소 찾기 창 안의 검색 버튼이 바깥 ‘활동 만들기’ 양식까지 제출해 창이 닫혔습니다 → 창을 `document.body`로 띄우고 검색 제출이 바깥으로 전파되지 않게 고쳤습니다.
- 새 화면 CSS가 기본 CSS보다 먼저 읽혀 지도 높이가 줄었습니다 → `finder.css`를 `styles.css` 뒤에 읽도록 `main.tsx`로 옮겼습니다.
- 오류를 고쳐도 칸 아래 오류가 남았습니다 → 첫 등록 시도 뒤에는 입력이 바뀔 때마다 다시 검사합니다.
- 테스트 빌드에 이전 7주차 빌드의 V6~V8이 남아 있어 마이그레이션 수가 틀렸습니다 → `clean` 후 다시 실행했습니다(코드 문제 아님).

## 실행하지 않은 것 (보완)

- 실제 Kakao 장소 검색·지도·주소 위치 찾기, 실제 1365 응답: 이 환경에서 dapi.kakao.com·apis.data.go.kr 접속이 막혀 있습니다. 서버에 키를 넣은 뒤 확인해야 합니다(응답 항목 이름·시·군·구 코드·1365 상세 링크 주소 포함).
- 배포 서버 반영: PR을 main에 합친 뒤 `set-keys.sh` 또는 `server-setup.sh` 실행 필요.
- `check-dev.sh`: 기존 개발 DB에 5~7주차 V6~V8이 적용돼 있어 이 브랜치로 기본 DB를 띄울 수 없어 실행하지 않았습니다(별도 DB로 화면 테스트만 실행).
