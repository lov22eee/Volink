## 발견·수정

- **신고 목록 SQL 오류:** Java 텍스트 블록은 줄 끝 공백을 지워, `WHERE` 뒤에 조건을 이어 붙이면 `WHEREr.status`가 됐습니다. 화면 테스트에서 증빙 버튼이 안 보여 발견했습니다. 공백을 조건 쪽에 넣고, 서버 테스트에 목록 조회를 추가했습니다(처음 서버 테스트는 목록을 부르지 않아 놓쳤음).
- **로그인이 가끔 풀림(3주차부터):** 페이지를 열 때 로그인 복원 요청이 동시에 두 번 나가(React 개발 모드의 이중 실행), 한 번만 쓸 수 있는 리프레시 쿠키가 두 번째 요청에서 거부되고 화면이 로그아웃 상태가 됐습니다. 5주차 검증 기록의 ‘원인 미확정 실패’가 이것입니다. 진행 중인 리프레시를 함께 쓰도록 고쳐 4주차 브랜치에 넣고 5~7주차에 합쳤습니다. 이후 전체 실행 2회 모두 통과.
- 계정 여러 개가 오가는 화면 테스트가 느린 실행에서 30초를 넘겨, 화면 테스트 제한 시간을 90초로 늘렸습니다.
- 처음 만든 시험용 PNG 바이트가 깨져 있어(체크섬 오류) 서버가 올바르게 거부했습니다. 올바른 PNG로 바꿨습니다(서비스 문제 아님).

## 실행하지 않은 것

- S3 보관: 지금은 서버 비공개 폴더입니다.
- 실제 사용자 사용성 평가.
- 배포 서버의 증빙 폴더 권한·백업 cron 실제 동작: 배포 스크립트에 넣었지만 서버에 반영하지 않았습니다.
- 테스트 담당 직접 확인([목록](manual-test-week07.md)).
